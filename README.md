# Mini Feed Simulator

A simple social media feed simulator built using vanilla JavaScript. This project focuses on managing posts and implementing core social media functionality without a user interface or external frameworks.

## Features

- **Create Posts** – Create posts with a unique ID, username, content and timestamp.
- **Like Posts** – Increase the number of likes on a specific post.
- **View Feed** – Retrieve all posts.
- **Sort by Newest** – Sort posts by their timestamps.
- **Sort by Likes** – Sort posts from most liked to least liked.
- **Filter by User** – Retrieve posts created by a specific user.

## Technologies Used

- JavaScript
- Node.js
